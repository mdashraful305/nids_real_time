# Data and Code Availability

The code, training notebook, experimental data, and results associated with this study are available at the following locations.

## Code and training notebook

[Google Colab training and offline-evaluation notebook](https://colab.research.google.com/drive/1Q4HVkbNzVFRanYxQpxc6Tv4KrCnozJvI?usp=sharing)

The notebook contains the model-training and offline-evaluation procedures used in this study.

## Notebook data and results

[Notebook data and generated results](https://drive.google.com/drive/folders/1-YsVShMvKb6d5S_O3iZM3J7_r6Jj7Du5?usp=sharing)

This folder contains the data, model artifacts, and experiment outputs required to reproduce the notebook-based analysis.

## Primary real-time data

[Primary real-time NIDS data](https://drive.google.com/drive/folders/1D_2lnjjJiFgaY-LIxBDA_OvYCsn21EUO?usp=sharing)

This folder contains the data collected during real-time monitoring experiments, including applicable Suricata logs, flow records, and associated outputs.
